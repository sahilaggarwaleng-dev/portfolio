SeaBot: Autonomous Underwater Drone

An autonomous underwater drone designed to trace nitrogen pollution in Long Island coastal waters, where cesspool runoff in Suffolk County drives harmful water-quality problems.

Role
Co-lead, four-person team
Status
Phase 0 design
Focus
Locomotion, camera, tethered power
Tools
SolidWorks, FEA

The problem

Nitrogen from residential cesspools reaches Long Island's aquifer, bays and the Sound. Monitoring it today is slow and manual. SeaBot aims to make repeated, low-cost sampling and tracing practical.

My approach

The Phase 0 design uses thrust-vectoring impeller locomotion and a live camera feed on a tethered power system. The project is organized in phases (SeaBot 0.1, 1.0 and so on) so each build proves one set of design decisions before the next.

Design highlights

  • Thrust-vectoring impellers for maneuverability without control surfaces
  • Live camera feed for operator situational awareness
  • Tethered power to remove battery-life limits during early testing
